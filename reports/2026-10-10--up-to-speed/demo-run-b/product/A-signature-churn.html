A · The top component, before and after

Component 0 is what the tool ranks first: the change a reviewer should read before anything else. The diagram puts the base and head call graphs on top of each other. Dashed red is only in base, green only in head, and grey is in both. In each repository the top component is mostly one signature change seen through tier-1 identity.

The diagram has its own Before / Delta / After switch at the top left, and an "Exact authored changes" list at the bottom.

Drawn with archify compare architecture from A-*/base.json and head.json, which scripts/gen_*_component0.py writes by hand from component 0 of each diff.json. Node and edge counts were checked against the document. Archify's own header line ("See what changed before you merge") is its boilerplate.
